## Executar localmente
O projeto não utiliza ferramentas de build nem dependências. Abra `index.html` no navegador ou use a extensão Live Server do VS Code.

## Publicar no GitHub Pages
1. Abra **Settings** neste repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde a publicação.

Endereço esperado: https://augustomc65.github.io/Portifolio/

## Observações
- O projeto de cadastro e login é apresentado como protótipo acadêmico com armazenamento local no navegador, não como autenticação segura de produção.
- A experiência profissional é descrita em nível geral, sem expor código, dados, clientes ou informações internas de terceiros.
